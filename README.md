# SwiftProjects

Projetos em Swift/SwiftUI que desenvolvi durante meus estudos, selecionados para portfólio.

| Projeto | Descrição | Destaques |
|---|---|---|
| [GameStop](GameStop) | App de loja de jogos | MVVM, Core Data, Keychain, async/await, injeção de dependências, testes unitários e de UI |
| [UnitTestingDemo](UnitTestingDemo) | Lista de usuários com testes unitários | XCTest, mocks, protocolos, cenários de sucesso/vazio/erro |
| [FlightsApp](FlightsApp) | Lista de voos com compra | SwiftUI, sheets, view model |
| [PlayerSpotify](PlayerSpotify) | Clone de tela de player de música | Layout SwiftUI, gradientes, SF Symbols |

## Requisitos
Xcode 26+ e iOS 26.1+ (simulador ou dispositivo). Abra o `.xcodeproj` de cada pasta e rode (⌘R).
